Скопируй файлы анализа с последней даты - название каталога в `archive` в формате YYYY-MM-DD, если каталог пуст, то за последние 7 дней в рабочий каталог проекта.

**Шаги:**

1. Определи сегодняшнюю дату и вычисли диапазон: от названия каталога в `archive` в формате YYYY-MM-DD, если каталог пуст, то (вчера − 6 дней) до вчера включительно.

2. В каталоге `/home/kiro/zerocoder/neiroGK_analyze/reports` найди все файлы, соответствующие маске `analysis_YYYY-MM-DD.md`, где дата в имени попадает в вычисленный диапазон.

3. Для каждого найденного файла:
   - Проверь, существует ли уже файл с таким именем в `02_analysis/periods/`.
   - Если файла нет — скопируй.
   - Если файл уже есть — пропусти и отметь в итоговом отчёте.

4. Выведи итоговый отчёт:
   - диапазон дат поиска
   - список скопированных файлов
   - список пропущенных (уже существовали)
   - список дат без файла (если за какой-то день файл не найден в источнике)
