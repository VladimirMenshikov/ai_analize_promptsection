---

Перенеси файлы проекта в архив, сохранив структуру каталогов.

**Шаги:**

1. Определи сегодняшнюю дату и сформируй путь назначения: `archive/YYYY-MM-DD/`.

2. Найди все файлы (рекурсивно) в каталогах:
   - `01_input/`
   - `02_analysis/`
   - `03_summary/`
   - `04_output/`

3. Для каждого найденного файла:
   - Вычисли относительный путь от корня проекта (например, `02_analysis/periods/analysis_2026-05-25.md`).
   - Создай соответствующий подкаталог внутри `archive/YYYY-MM-DD/` (если ещё не существует).
   - Перенеси файл туда, сохранив относительный путь: `archive/YYYY-MM-DD/02_analysis/periods/analysis_2026-05-25.md`.

4. После переноса всех файлов убедись, что исходные каталоги (`01_input/`, `02_analysis/`, `03_summary/`, `04_output/`) остались на месте и пусты (или содержат только пустые подкаталоги).

5. Каталоги `05_templates/` и `archive/` **не трогай**.

6. Выведи итоговый отчёт:
   - путь созданного архива
   - количество перенесённых файлов с разбивкой по исходным каталогам
   - список файлов, которые не удалось перенести (если есть), с причиной
